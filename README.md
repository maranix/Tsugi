# Tsugi (次)

Tsugi is a modern native iOS client for self-hosted [Suwayomi](https://github.com/Suwayomi/Suwayomi-Server) manga servers, built using Swift 6, SwiftUI, and modern concurrency.

## Requirements

- **iOS 26.0+**
- **Xcode 26+**
- **Swift 6.0**
